# Laravel REST API

This repository contains a Laravel-based RESTful API project demonstrating various features such as database integration, validation, resource controllers, and authentication. The codebase is organized into branches, each focusing on a particular aspect of API development.

---

## 📁 Branches Overview

| Branch Name           | Description                                                                                   |
|-----------------------|-----------------------------------------------------------------------------------------------|
| `main`                | The main branch with the latest stable API implementation.                                    |
| `1.1master`           | Master branch with the initial or core API setup.                                            |
| `2.-database`         | Includes database migrations, seeders, and Eloquent models setup.                            |
| `3.update-delete`     | Implements update and delete endpoints for resources.                                        |
| `4.validation`        | Adds request validation for API endpoints to ensure data integrity.                          |
| `5.resource`          | Uses Laravel resource controllers and API resources for structured JSON responses.           |
| `6.authentication`    | Implements API authentication using Laravel Sanctum or Passport.                             |
| `7.basic-authentication` | Demonstrates basic authentication implementation (HTTP Basic Auth).                       |

---
